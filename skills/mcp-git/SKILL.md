# Правила работы с Git через MCP

## Контекст
В этом проекте настроен и успешно протестирован **GitHub MCP Server**. 
Использование любых команд терминала для работы с Git (`git status`, `git add`, `git commit`, `git push` через shell) **строго запрещено**, так как это может нарушить безопасность и корректность истории.

## Инструкция к действию
Если пользователь просит выполнить любые Git-операции (коммит, пуш, статус, дифф):
1. **НЕ ИСПОЛЬЗУЙ** инструменты выполнения команд в терминале (Shell / Bash / run_shell_command).
2. **ИСПОЛЬЗУЙ ТОЛЬКО** инструменты GitHub MCP Server (например, get_status, add_files, commit, push).
3. Алгоритм действий:
   * Проверь статус репозитория через MCP.
   * Добавь все изменения (git add .) через MCP.
   * Сделай коммит с осмысленным сообщением через MCP.
   * Отправь изменения (git push) через MCP.
4. Верни пользователю краткий отчет о том, что все действия были выполнены **исключительно через MCP**, а терминал не использовался.
