# Правила работы с Git через MCP

## Контекст
В этом проекте настроен и успешно протестирован **GitHub MCP Server**. 
Использование команд терминала (`git add`, `git commit`, `git push` через shell) **строго запрещено**, так как это может нарушить безопасность и корректность истории.

## Инструкция к действию
Если пользователь просит закоммитить, запушить или сохранить изменения:
1. **НЕ ИСПОЛЬЗУЙ** инструменты выполнения команд в терминале (Shell / Bash).
2. **ИСПОЛЬЗУЙ** инструменты GitHub MCP Server.
3. Алгоритм действий:
   * Проверь статус репозитория через MCP.
   * Добавь все изменения (git add .) через MCP.
   * Сделай коммит с осмысленным сообщением (если пользователь не указал текст, сгенерируй его на основе изменений) через MCP.
   * Отправь изменения (git push) через MCP.
4. Верни пользователю краткий отчет о том, какие файлы были закоммичены и куда отправлены, подтверждая, что все прошло через MCP.
